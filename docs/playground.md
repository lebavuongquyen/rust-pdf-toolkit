### Key Capabilities in Browser:
- **Scan & Inspect Fields**: Scans all AcroForm interactive form fields in real-time.
- **Form Filling**: Populates values from JSON with optional static flattening.
- **Watermark & Page Numbering**: Real-time rendering of customizable headers, footers, stamps, and Bates sequences.
- **Real-Time PDF Preview**: Instant visual preview rendered natively in the browser canvas.
